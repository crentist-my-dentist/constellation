# Feedback for the person who set this up

Notes about **the system itself** — a rule that doesn't fit your life, an instruction
that doesn't work, something Claude keeps getting wrong. Claude adds entries here when
it hits one.

Nothing personal goes in this file. No journal entries, no reflections, no names, no
details about your situation — only what broke and what should have happened. It's
written this way so you can send it to whoever set this up without sending them any
part of your life.

To send it: copy an entry and paste it into a message. Then delete it from here.
